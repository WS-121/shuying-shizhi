# 疏影拾知 · 碎片化知识防遗忘归档系统

> 把「收藏」变成「记住」——一个纯前端的碎片知识归档与艾宾浩斯复习提醒系统。

---

## 项目简介

我们每天刷短视频、听课、读文章，遇到有用的内容就点「收藏」，但收藏夹里几百条记录几乎再也不会被打开。问题不在于不想复习，而在于内容散落在各个平台，没有任何机制提醒你「该复习了」。

**疏影拾知** 把零散的知识点统一收进来，自动分类、自动整理，再按人类记忆规律提醒复习，让碎片知识真正沉淀下来。

整个系统为纯前端实现，无后端依赖，数据全部保存在浏览器本地。

## 核心功能

### 1. 多源知识采集

- 支持三种来源录入：短视频通识、课堂录音、手动录入
- 粘贴视频链接可自动解析标题，并提取关键词、生成摘要，降低录入成本
- 视频解析依赖本地 Python 代理（见「本地运行」）

### 2. 双层分类体系

- 6 个内置固定分类：短视频通识知识、课堂课程知识点、读书随笔摘录、技术编程积累、考试备考重点、生活经验备忘
- 支持自定义分类的增、删、改，按个人习惯自由组织

### 3. 文本智能预处理

自动去重、自动提取关键词标签、生成精简摘要。采用规则化实现，完全离线、速度快、结果可预期。

### 4. 基于艾宾浩斯遗忘曲线的智能复习

- 复习间隔按 `1 / 2 / 4 / 7 / 15 / 30 / 60 / 120` 天递增
- 每条知识点记录「已复习次数」与「下次复习时间」
- 标记已复习后自动推进到下一间隔，到期知识点自动提醒

### 5. 双层检索体系

- 本地全文检索：标题、正文、标签均可搜索
- 拓展检索：一键跳转搜索引擎，查找该话题的更多资料

### 6. 数据备份与迁移

所有数据可一键导出为 JSON 文件，换设备、换浏览器导入即可恢复。

## 界面与交互

- **三栏布局**：左侧分类导航 / 中间知识卡片 / 右侧数据看板
- **知识卡片详情弹窗**：点击卡片任意位置即可查看完整正文、标签、链接、复习状态，长内容内部独立滚动
- **数据看板**：近 90 天录入热力图、近 30 天学习趋势、分类占比环形图，全部基于本地真实数据实时计算
- **响应式适配**：宽屏保持三栏；中等宽度按比例收紧；窄屏右侧看板折叠为右上角悬浮按钮，点击以抽屉形式展开

## 技术栈

| 层次 | 技术 | 说明 |
|---|---|---|
| 结构 | HTML5 | 单页应用 |
| 样式 | Tailwind CSS v3 (CDN) + 自定义 CSS 变量 | 快速布局 + 低饱和书卷配色 + 主题变量 |
| 交互 | 原生 JavaScript (ES6+) | 无框架、无构建工具，零依赖启动 |
| 图表 | ECharts 5（本地引入） | 热力图、趋势图、环形图 |
| 图标 | Font Awesome (CDN) | 界面图标 |
| 存储 | localStorage | 数据完全本地化，不上传 |
| 视频解析 | Python 本地代理（可选） | 仅在需要解析视频链接时使用 |

### 数据存储

localStorage 中维护三个键：

| Key | 内容 |
|---|---|
| `syzz_categories` | 分类列表 |
| `syzz_knowledge` | 知识点列表 |
| `syzz_settings` | 系统设置 |

## 本地运行

### 方式一：直接打开

直接用浏览器打开 `index.html` 即可使用全部核心功能（录入、分类、复习、看板、检索、备份）。

### 方式二：本地静态服务器（推荐）

```bash
# Python 3
python -m http.server 5500
```

然后访问 `http://localhost:5500`。

### 方式三：启用视频链接解析（可选）

视频解析需要本地代理服务，另开一个终端：

```bash
python video_proxy.py
```

代理默认运行在 `5600` 端口，视频解析功能依赖它。若不需要解析视频链接，可跳过此步。

## 已知限制

- **无后端**：数据不跨设备同步，换设备需手动导出 / 导入 JSON
- **预处理为规则实现**：非语义模型，面对复杂内容时准确率有限
- **视频解析依赖网络通道**：优先调用本地 Python 代理，未启动时自动降级到公共 CORS 代理链；纯静态托管环境下若本地代理未运行，解析成功率会下降，其余功能不受影响
- **仅面向浏览器**：暂未提供移动端原生应用
